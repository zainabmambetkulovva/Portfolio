📌 ПОРТЫ:
   Frontend:  http://localhost:4000
   Backend:   http://localhost:4001

═══════════════════════════════════════════════════════════

🚀 ПЕРВЫЙ ЗАПУСК (делается один раз):

1. Установить пакеты:
   npm install

2. Проверить БД:
   npm run test-db

3. Запустить ВСЁ СРАЗУ:
   Двойной клик: start-all.bat
   (Это запустит Backend И Frontend одновременно!)

4. Инициализировать БД (через 5 секунд после запуска):
   Открыть в браузере: http://localhost:4001/api/init

5. Открыть сайт:
   http://localhost:4000

═══════════════════════════════════════════════════════════

🔄 ЕЖЕДНЕВНЫЙ ЗАПУСК (после первой настройки):

СПОСОБ 1 (ПРОСТОЙ):
   Двойной клик: start-all.bat
   Откроется Backend и Frontend вместе!

СПОСОБ 2 (ВРУЧНУЮ):
   1. Двойной клик: start-server.bat (Backend)
   2. Двойной клик: start-dev.bat (Frontend)

3. Открыть: http://localhost:4000

⚠️ ВАЖНО: Backend и Frontend должны быть запущены ОДНОВРЕМЕННО!
   Не закрывайте окна терминалов!

(Инициализацию /api/init больше НЕ НУЖНО запускать!)
